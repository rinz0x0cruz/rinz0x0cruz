### Jobscope

Transparent job matching over reviewed ATS feeds, with deterministic scam checks and
human-controlled application preparation.

### Quorum

Reproducible comparisons of model-deliberation strategies using versioned task packs,
deterministic grading, and an offline mock provider.

[Source and benchmark guide](https://github.com/rinz0x0cruz/quorum)

## Working principles

- Keep the core deterministic and usable without model or API access.
- Preserve the meaning and limitations of each evidence source.
- Publish inspectable artifacts while keeping private data and implementation behind explicit boundaries.
- Treat accessibility, tests, delivery verification, and recovery as part of the work.
